# pages/

Una carpeta por **pantalla de nivel superior** (lo que enruta el router).
Componen piezas de `features/` y `components/`; no contienen lógica de datos.

- YearView/ vista Año (rejilla de 12 mini-meses)
- MonthView/ vista Mes (celdas con collage) — vista estrella
- WeekView/ vista Semana (detalle por día)
- DayView/ vista Día (portada, diario, fotos, tareas, métricas)
- Analytics/ dashboard de gráficos
